# Sistema Help Desk Responsive

Este proyecto contiene la implementación responsive del sistema Help Desk, aplicando estilos CSS, Flexbox, CSS Grid y Media Queries para adaptar las páginas a escritorio, tablet y móvil.

## Páginas desarrolladas

* Dashboard principal: `index.html`
* Reporte de incidentes: `reportar.html`
* Listado de tickets: `tickets.html`

## Tecnologías utilizadas

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

## Resultado

El diseño permite una visualización adaptable en diferentes tamaños de pantalla, manteniendo una estructura clara, ordenada y funcional para el sistema de gestión de incidentes.
